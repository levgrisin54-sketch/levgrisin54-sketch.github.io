## Локальный запуск и проверка

Откройте `index.html` в браузере. Для полного прогона нужен установленный Chrome:

```powershell
npm run qa
```

Проверка проходит главную страницу, Second Look, курс, отдельный урок и HotTour; проверяет ширины до 320 px, режим без анимации, интерактивные сценарии и все локальные пути. Скриншоты и отчёт сохраняются в `.qa/` и не публикуются.

## Обновление опубликованной версии

После правок выполните в этой папке:

```powershell
npm run qa
git add .
git commit -m "Update portfolio"
git push
```

GitHub Pages автоматически обновит сайт через несколько минут.
